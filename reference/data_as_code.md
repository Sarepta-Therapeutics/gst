# Convert data.frame to R code that creates identical dataset

Convert data.frame to R code that creates identical dataset

## Usage

``` r
data_as_code(data)
```

## Arguments

- data:

  data.frame to convert (data.frame)

## Value

object containing code to generate data.frame (character/scalar)
