# Launch the GST Power App

Launch the GST Power App

## Usage

``` r
gst_power_app(runApp = TRUE)
```

## Arguments

- runApp:

  should the app be run on completion, default is TRUE

## Value

A Shiny app

## Examples

``` r
if (interactive()) {
  gst_power_app()
}
```
