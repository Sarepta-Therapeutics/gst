# Calculate Power

Calculate Power

## Usage

``` r
get_power(oes, n0, n1 = n0, df = n0 + n1 - 2, alpha = 0.05)
```

## Arguments

- oes:

  operational effect size

- n0:

  sample size in placebo group

- n1:

  sample size in treatment group

- df:

  degree of freedom

- alpha:

  significance level

## Value

power
