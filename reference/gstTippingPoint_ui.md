# Effect size tipping point calculation

Given Endpoint 1 effect size ES1 and correlation with endpoint 2 Rho,
calculate tipping point for Effect Size 2, such that the joint endpoint
effect size dips below the first (larger) Endpoint 1 ES1. This is based
on Dallow (2016)

## Usage

``` r
gstTippingPoint_ui(id)
```

## Arguments

- id:

  namespaced ID (character/scalar)
